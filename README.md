# 간다 GO — 동작 출장마사지·홈타이 안내 사이트

서울 동작구 출장마사지·홈타이 예약 안내 정적 사이트입니다.
전화예약: **0508-202-4719**

## 구조

```
build.py          # 정적 사이트 빌드 스크립트 (Python 3, 의존성 없음)
content/*.md      # 페이지별 콘텐츠 (front matter + 본문)
assets/style.css  # 공통 스타일
index.html 등     # build.py 가 생성한 결과물 (URL 구조 그대로 디렉터리 생성)
sitemap.xml       # index 페이지만 포함 (자동 생성)
robots.txt        # 자동 생성
```

## 빌드

```bash
python3 build.py
```

실행 시 모든 페이지의 본문 글자수(공백 제외)와 index/noindex 상태가 출력됩니다.

배포 도메인이 확정되면 `build.py` 상단의 `SITE_URL` 을 실제 도메인으로 변경한 뒤
다시 빌드하세요 (canonical·sitemap 에 반영됩니다).

## 페이지 구성

- 메인 `/` — 동작 출장마사지 허브
- 지역별 안내 `/dongjak-gu/` + 대표 동 8개 (노량진동·상도동·본동·흑석동·동작동·사당동·대방동·신대방동)
- 지하철역별 안내 `/dongjak-gu/stations/` + 역 16개 (1·4·7·9호선, 신림선)
- 테마별 안내 `/themes/` + 테마 14개
- 코스안내 `/courses/`, 예약안내 `/reservation/`, 이용가이드 `/guide/`, 후기 `/reviews/`, 고객센터 `/support/`

## SEO 운영 규칙 (빌드 스크립트가 강제하는 것 포함)

1. **숫자 행정동 통합** — 노량진1·2동→노량진동, 상도1~4동→상도동, 사당1~5동→사당동,
   신대방1·2동→신대방동. 숫자 동 개별 페이지는 만들지 않습니다.
2. **환승역 단일 URL** — 환승역은 여러 노선 메뉴에 노출돼도 페이지는 하나만 운영합니다.
3. **조합 페이지 금지** — `역+테마`, `지역+테마`, `출구별` 페이지를 만들지 않습니다.
   해당 키워드는 역·동·테마 페이지 본문과 FAQ에서만 자연스럽게 언급합니다.
4. **글자수 기준** — 본문 2,000자(공백 제외) 미만 페이지는 빌드 시 자동으로
   `noindex` 처리되고 sitemap 에서 제외됩니다.
5. **복붙 금지** — 지역명·역명만 바꾼 페이지를 만들지 않습니다. 새 페이지를 추가할 때는
   해당 생활권의 실제 특징으로 고유하게 작성하세요.
6. **푸터 나열 금지** — 푸터에 지역명·역명을 대량 나열하지 않습니다 (템플릿 고정).
7. **FAQ** — 페이지마다 3~5개 고유 작성. 빌드 시 FAQPage 구조화 데이터가 자동 생성됩니다.
8. **메뉴명은 짧게** — 하위 메뉴는 "상도동", "사당역"처럼 표기하고, 키워드는
   각 페이지의 H1·SEO Title 에서만 정확히 사용합니다.

## 페이지 추가 방법

`content/` 에 마크다운 파일을 추가하고 `python3 build.py` 를 실행합니다.

```markdown
---
url: /경로/
seo_title: 페이지 제목
description: 메타 설명 (110자 내외)
h1: 페이지 H1
section: regions|stations|themes|courses|reservation|guide|reviews|support|service
nav_label: 짧은 메뉴명
related: 라벨=/url/ | 라벨2=/url2/
---
```
